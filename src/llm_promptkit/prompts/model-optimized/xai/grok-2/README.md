## Special Considerations

If the historical stack cannot run those tools, provide dated sources and disclose that limitation rather than pretending it searched X.

Directness and humor are author-selected styles, not documented accuracy or safety capabilities. State the evidence cutoff, authorized tools, output format, and stopping rule explicitly. Tool availability is configured by the client, and suggested tests are not executed tests. The re-authored prompts remain not model-tested; no vendor benchmark is reported as a PromptKit score.
